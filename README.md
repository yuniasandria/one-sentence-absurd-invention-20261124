An entry for the [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty on [make.fun](https://make.fun/r/6cmdpsm5): one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

## The pitch

> A Wi-Fi router on tiny legs that follows you from room to room so the signal never dies the moment you settle on the sofa with your laptop and a deadline.

## How it works

`main.py` (Python 3.13, standard library only) writes the pitch to `/output/entry.txt`.

Run it with:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```
